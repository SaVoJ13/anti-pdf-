### 3.1 English (`en`)

Looking for a fast, secure, and privacy-respecting PDF reader with essential page management tools? **Volum PDF: Reader & Tools** is engineered for seamless document handling without subscriptions, account registrations, or invasive cloud uploads.

#### 🚀 Key Features

**Lightning-Fast PDF Viewing**
- Smooth and fluid vertical scrolling and pinch-to-zoom.
- Instant rendering of large multi-page documents and scanned files.
- Text selection, copy, and quick in-document search (on Android 12+).
- Support for password-protected and encrypted PDF documents.
- Automatically saves your reading position so you can pick up right where you left off.

**Built-In Page Tools (No Cloud, 100% Private)**
- **Merge PDFs:** Combine multiple PDF documents into a single organized file in seconds.
- **Split & Extract Pages:** Select specific page ranges (e.g. 1-3, 5, 8) and save them as a clean new PDF.
- **Rotate Pages:** Fix upside-down or landscape pages by rotating 90°, 180°, or 270°.
- **Delete Pages:** Easily remove unnecessary pages from your files.
- **Images to PDF:** Convert multiple photos and scans (JPEG, PNG) into a high-quality PDF.

**Privacy & Security First**
- **Zero Cloud Uploads:** No external servers, no tracking, no registration.
- **Safe Storage Access:** Direct access through Android's secure file picker. We never ask for full storage permissions (`MANAGE_EXTERNAL_STORAGE`).
- **Fully Functional Offline:** Read documents and use all page tools anywhere, anytime, without an internet connection.

**Clean & Respectful User Experience**
- Modern Material 3 interface with automatic Dark and Light themes.
- No intrusive full-screen popups while reading or opening files.
- Offline mode features zero ads and zero empty placeholders.

Download **Volum PDF: Reader & Tools** today — fast, lightweight, and genuinely private.
