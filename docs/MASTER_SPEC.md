# MASTER_SPEC — PDF Reader для Android
Версія: v0.0 (чернетка). Веде лише Керівник проєкту.

## Статус
Фаза 0 (дослідження). Код не пишеться до затвердженого MVP.

## Ціль
Android-застосунок для читання й роботи з PDF, монетизація рекламою, публікація в Google Play.

## Затверджені рішення (власник, 2026-11-03)
| # | Рішення |
|---|---------|
| R1 | Особистий акаунт Google Play (наслідки: закритий тест ≥12 тестувальників × ≥14 днів; публічні дані трейдера за DSA) |
| R5 | Закритий код. Репозиторій на GitHub тимчасово публічний, потім стане приватним; до приватизації не комітити нічого цінного й закритого |

| R8 | Мови інтерфейсу: uk, en, ru, de |

## Незмінні правила
- Усі ліцензії сумісні із закритою комерційною публікацією, якщо власник не вирішив інакше.
- Доступ до файлів лише через SAF; MANAGE_EXTERNAL_STORAGE тільки за обовʼязкової потреби й рішення власника.
- Жодної аналітики й збору даних понад необхідне для реклами та без згоди. Файли користувача не покидають телефон без явної згоди.
- Секрети (ключі підпису, паролі, токени) ніколи не в репозиторії чи чаті.
- Платна дія спершу власнику з точною сумою й альтернативою.

## Ролі
Керівник проєкту; PDF-ядро; Android і UI; Монетизація і Google Play; QA і безпека (+ ролі за потреби).

## Процес
Гілки `feature/...`, пуш/PR/злиття лише власник. Паралельно лише через git worktree. Кожен агент завершує підсумком: Що зроблено / Що змінено / Рішення / Що передати далі / Відкриті питання.

## Якість
Бюджети продуктивності (час відкриття, памʼять, сторінки на великих файлах) на release-збірці на реальному телефоні (Galaxy S24 Ultra). Тести: сотні сторінок, скановані, зашифровані, пошкоджені, поворот, завершення процесу. Критичні висновки перевіряє агент, що не писав код.

## Структура репозиторію (пропозиція)
```
pdf-reader-android/
  app/                 # Android-застосунок (UI)
  core-pdf/            # обгортка над PDF-рушієм (контракт у CONTRACTS.md)
  core-ads/            # реклама й згода (UMP)
  docs/                # MASTER_SPEC, CONTRACTS, THIRD_PARTY, project_log
    research/          # звіти й промти
    store/             # матеріали для Google Play, політика конфіденційності
  testdata/            # ТІЛЬКИ власні/вільні тестові PDF (без чужих файлів)
```
Модулі остаточні після вибору рушія.
