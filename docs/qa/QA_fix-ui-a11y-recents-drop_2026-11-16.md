Читач бере підказку з інтенту лише коли `savedInstanceState == null`; після відновлення процесу визначає наново. Відкриття з «Останніх», інструментів, сканера, органайзера йдуть без підказки: читач визначає сам до запису (запис уже є, тож «не нове», давній запис не стирається).

Тимчасовий IO-збій при першому відкритті нормального файлу прибере лише новий рядок; наступне відкриття створить його знову, даних не втрачається. Ризик прийнятний (низький).
