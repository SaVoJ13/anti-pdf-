## Дефекти
Блокерних немає. Низьке спостереження (не регресія, є на `main`):
1. **Рамка тексту, що виходить за правий край сторінки, після «Змінити текст» обрізається по краю й текст ламається.** Кроки: «Додати текст» (`ALPHA`), потягнути ручку розміру до ≈102 pt, перетягнути текст праворуч так, щоб рамка вийшла за край сторінки; «Змінити текст», дописати Enter + `BETA`, підтвердити. Результат: «ALPH / A / BETA» (у першому прогоні «A L P H A B E T A» по літері, розмір 91 pt, без ландшафту). Відтворено однаково на PR (`d5da91d`) і на `main` (`ad5a18b`, збірка `lastUpdateTime` 21:17:50). Імовірна причина (НЕ ПЕРЕВІРЕНО в коді): при правці ширина рамки обмежується краєм сторінки. Це, ймовірно, і є спостереження (а) з PR #7: у ландшафті рамка була ширшою за поточну сторінку. Дані не втрачено, елемент редагований.
2. Зауваження: перетягування й потяг за ручку дозволяють вивести рамку за межі сторінки (НЕ ПЕРЕВІРЕНО, що саме вшивається при збереженні такого елемента).
