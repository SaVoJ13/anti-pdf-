## 2. Темна нижня панель інструментів (`placeToolBar` — кадри `00:01`–`00:16`)

- **ID у розмітці:** `@id/placeToolBar` / `@id/placeToolBarRow`
- **Візуальний стиль:**
  - Темна графітова панель (`#1E1F22`) внизу екрана.
  - Світлі іконки (`#F3F4F6`), активний інструмент підсвічений круглою капсулою `#3D4048` (`44×44 dp`), неактивні кнопки (`Undo`/`Redo`/`Delete` без цілі) мають прозорість `38%`.
- **8 слотів керування однією рукою (`≥ 48×48 dp`):**
  1. `btnSlotText` (`T`) — інструмент **Текст**;
  2. `btnSlotPen` — інструмент **Перо / Малювання**;
  3. `btnSlotDelete` — **Видалити** виділений об'єкт;
  4. `btnSlotSelect` — **Виділення / Переміщення** об'єктів на сторінці;
  5. `btnSlotAction` — швидка вставка (**Галочка `✓`**, **Хрестик `✗`**, **Підпис**, **Зображення**);
  6. `btnPlaceUndo` (`↶`) — **Скасувати**;
  7. `btnPlaceRedo` (`↷`) — **Повторити**;
  8. `btnSlotOptions` — відкрити/закрити контекстну картку параметрів.

## 3. Контекстна спливаюча картка параметрів (`placeOptionsCard` — кадри `00:03`–`00:12`)

- **ID у розмітці:** `@id/placeOptionsCard`
- **Візуальний стиль:**
  - Плаваюча темна картка (`#2B2D31`), заокруглення кутів `24dp`, тінь `8dp`, розташована по центру безпосередньо над нижньою панеллю.
- **Склад секцій (усе на одній компактній картці за зразком `00:03`–`00:12`):**
  1. **Шапка:** назва активного інструмента (`tvOptionsTitle`) ліворуч + кнопка закриття `×` (`btnOptionsClose`) праворуч.
  2. **Вибір типу пера або дії:**
     - Для малювання (`placeInkPresetGroup`): чіпи `Ручка`, `Маркер`, `Хайлайтер`.
     - Для вставки (`placeSecChooser`): кнопки `✓`, `✗`, `Підпис`, `Зображення`.
  3. **Ряд розміру / товщини з кнопками `−` та `+` (`placeSecSize`):**
     - Кнопка `−` (`btnSizeMinus`, `48×48 dp`), горизонтальний `Slider` (`placeSizeSlider`) із числовим значенням на повзунку, кнопка `+` (`btnSizePlus`, `48×48 dp`).
  4. **Перемикач «Випрямлення ліній» (`placeSecStraighten`):**
     - Текст `Випрямлення ліній` ліворуч + `MaterialSwitch` (`switchStraighten`) праворуч.
  5. **Керування зображенням (`placeImageBlock`):**
     - Кнопки `-90°`, індикатор кута (`0° / 90° / 180° / 270°`), `+90°` та кнопка `На всю сторінку`.
  6. **Палітра кольорів (`placeColorGrid`):**
     - Кружечки `SwatchView` із білою галочкою **`✓`** всередині активного кольору + райдужний кружечок вибору власного кольору. Безпечна адаптація кількості колонок при повороті екрана (усунення дефекту **К2**).
