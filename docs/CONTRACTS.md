# CONTRACTS — контракти між модулями
Веде лише Керівник проєкту. Версії v0.N.

## v0.0
Контрактів немає. Їх буде визначено після затвердження PDF-рушія та MVP.

Планові контракти (лише назви, без змісту):
- `core-pdf` ↔ `app`: відкриття документа, рендер сторінки, пошук, операції зі сторінками.
- `core-ads` ↔ `app`: стан згоди, показ реклами, режим без реклами/офлайн.
