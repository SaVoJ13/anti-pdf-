## 3. `screen_off_timeout` телефона
Залишився зміненим після прогонів (у QA 3c — 60 с, наприкінці QA 3e — 600 с), початкове значення невідоме. Власник повертає бажане значення сам: Налаштування → Дисплей → Тайм-аут екрана. **Статус:** чекає Власника.

## 4. Тестові записи в «Останніх» застосунку та вкладки Chrome
Лишилися записи в списку «Останні» застосунку (`short3`, `big60`, `enc`, `form`, `long120`, `fm_*_qa`, `e_*_qa`, `e_*_qa_edited` — самих файлів на пристрої вже немає) та кілька локальних тестових вкладок у Chrome (`localhost:8765/...`). Власник прибирає вручну на телефоні. **Статус:** чекає Власника.
